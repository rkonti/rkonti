## Somethings I have made
[Thinkpower](https://github.com/rkonti/thinkpower)
 * A lightweight terminal-based power monitoring tool for Lenovo Thinkpad laptops running linux, wirtten in python.
 * Display real-time power usage and component breakdown(CPU, GPU, display, keyboard backlight) in a minimal text interface.
 * Power by psutil, with no graphical dependecies.
 * Designed to run cleanly and efficiently directly in the terminal.
